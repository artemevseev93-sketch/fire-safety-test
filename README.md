# 🔥 Проверка знаний по пожарной безопасности

Веб-приложение для проведения вводного и первичного противопожарных инструктажей с проверкой знаний.

## 🌐 Онлайн-версия

**Открыть программу:** [https://ваш-логин.github.io/fire-safety-test/](https://ваш-логин.github.io/fire-safety-test/)

> ⚠️ Замените `ваш-логин` на свой GitHub-username

## 📋 Возможности

- 📘 Два вида инструктажа: **вводный** и **первичный**
- ⏱ Таймер 30 минут, проходной балл 80%
- 👥 Авторизация с ролями (администратор / работник)
- 🔑 Смена пароля пользователем
- 🔄 Сброс пароля администратором
- 📊 Журнал результатов с фильтрами и поиском
- 📥 Экспорт в **Excel (XLSX)** и **CSV**
- 💾 Экспорт/импорт журнала в **JSON** (для переноса между устройствами)
- 🖨 Печать протокола

## 🔐 Демо-доступы

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | `admin` | `admin123` |
| Работник | `user` | `user123` |

> ⚠️ Сразу после первого входа смените пароли через кнопку «🔑 Пароль» в шапке.

## 📱 Как использовать

1. Откройте ссылку на любом устройстве (ПК, планшет, телефон)
2. Войдите под своими учётными данными
3. Выберите вид инструктажа
4. Заполните данные работника
5. Пройдите тест
6. Получите протокол (можно распечатать)
7. Результат автоматически сохранится в журнал

## 💾 Перенос журнала между устройствами

1. На устройстве А: админка → **📤 Экспорт журнала (.json)**
2. Перенесите файл (флешка, email, облако)
3. На устройстве Б: админка → **📥 Импорт журнала (.json)**
4. Записи объединятся, дубликаты пропустятся

## ⚠️ Технические особенности

- Данные хранятся в **localStorage** браузера — привязка к домену и устройству
- Для синхронизации между устройствами используйте **JSON-экспорт/импорт**
- Excel-экспорт требует интернет (загружает библиотеку SheetJS с CDN)
- Всё остальное работает офлайн

## 📄 Лицензия

Свободное использование в образовательных и рабочих целях.
